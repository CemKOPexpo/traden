# AI Venture Studio

## Zo begin je
1. Zet deze map op je computer en open hem in Claude Code.
2. Vul `docs/EIGENAAR.md` zoveel mogelijk in (vooral het budget).
3. Plak de tekst uit `EERSTE_OPDRACHT.md` als eerste bericht in Claude Code.
4. Lees na elke fase het verslag en schrijf in `docs/VOORTGANG.md`: "Fase X goedgekeurd — [datum]". Pas daarna begint de volgende fase.

## Bestanden
| Bestand | Doel |
|---|---|
| `CLAUDE.md` | Werkregels die Claude Code elke sessie leest |
| `EERSTE_OPDRACHT.md` | De startopdracht om te plakken |
| `docs/VISIE.md` | Volledige visie en ontwerpeisen |
| `docs/FASEN.md` | Fasenplan met opleveringen en klaar-criteria |
| `docs/EIGENAAR.md` | Jouw budget, grenzen en voorkeuren (zelf invullen) |
| `docs/VOORTGANG.md` | Status, goedkeuringen en logboek |
| `docs/BESLUITEN.md` | Besluitenlog |
